GITHUB 

GIT is a open source version controling tool that keeps the track of change in code, where GITHUB is the website that allows to store and manage
their code using GIT

1. Helps to collaborate so a team can work on single project
2. Track the complete history of code or project

Note : To finalize any change on GIT HUB is a two steps process, first we need to add the change and than commit the change to finalize changes
		So GIT Hub keeps the track of every commit done by user on code or project.
		We need to provide a message on every commit.
		
		We can use HTML tags to manage Readme.md

git push origin main : After this command we can see the change on GITHUB as well


init command : it is use to make a local repo so we can sync locally created repo to to github. by running command - > git init
				we will get a new directory with name of .git, which we can commit to GIT HUB
				
If we have created any project on local and we want to push it into GITHUB website than create the project on local
git remote add origin  <link>  			//using this command we can push our project on GITHUB
git branch								// command let us know, at what branch we are currently
git branch -M new_name 						//Use to Rename the branch, where main
git push -u origin main						// use -u flag to tell that we want to do all the operation on origin main only.
git checkout new_branch						//use to switch branch
git checkout -b new_branch					// use to create new branch
git branch -d branch_name					//use to delete branch, we cant delete the current branch, we need to switch the branch first and than
											we can delete that branch

git diff branch_name					//compairing current branch with another branch
git pull origin main					// to pull the changes from remote to local

git merge branch_name					//merging 	another branch with current branch
