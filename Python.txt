Format - Strings: As we learned in the Python Variables chapter, we cannot combine strings and numbers like this:
	
	Wrong way :
		age = 36
		#This will produce an error:
		txt = "My name is John, I am " + age
		print(txt)
	
	But we can combine strings and numbers by using f-strings or the format() method!
	
Note : F-String was introduced in Python 3.6, and is now the preferred way of formatting strings.
		To specify a string as an f-string, simply put an f in front of the string literal, and add curly brackets {} as placeholders for variables and other operations.
		
		f-string in Python means formatted string literal. It lets you easily put variables or expressions directly inside a string.
		
		Create an f-string:
		age = 36
		txt = f"My name is John, I am {age}"
		print(txt)
		
	
A placeholder can include a modifier to format the value.
A modifier is included by adding a colon : followed by a legal formatting type, like .2f which means fixed point number with 2 decimals:

Display the price with 2 decimals:
	price = 59
	txt = f"The price is {price:.2f} dollars"
	print(txt)

Escape character: To insert characters that are illegal in a string, use an escape character. An escape character is a backslash \ followed by the character you want to insert.

txt = "We are the so-called "Vikings" from the north."			// this will give error
txt = "We are the so-called \"Vikings\" from the north."		// the correct way to use  escape character.

other Escape character :  \'  , \\ ,  \n,  \r, \t , \b ,\f


Python Collections 

There are four collection data types in the Python programming language: All the collections can have multiple data type value at once

List is a collection which is ordered and changeable. Allows duplicate members.
Tuple is a collection which is ordered and unchangeable. Allows duplicate members.
Set is a collection which is unordered, unchangeable*, and unindexed. No duplicate members.
Dictionary is a collection which is ordered** and changeable. No duplicate members.


List: data type used to store multiple items in a single variable. Lists are created using square brackets:
	  Example: thislist = ["apple", "banana", "cherry"]
			   print(thislist)
			   
	  Duplicate  value allowed
	  List are mutable, meaning that we can change, add, and remove items in a list after it has been created.
	  List are Ordered, means the elements maintain a specific sequence/order, and you can access them using an index.
	  

Basic Functions
	Access Item: thislist[0], thislist[-1]
	Change Item : thislist[0] = grappes
	Add Item : thislist.append("Orange")
	Remove Item : thislist.remove("banana")
	
	For Loop
			for x in thislist
			  print(x)
			  
	Index loop
			for i in range(len(thislist)):
				print([i])
				
	While loop 
			while (i<len(thislist):
				print(thislist[i])
				i=i+1
		
	Sorting : thislist.sort()

	join list : list3 = list1 + list2

Python Functions: A function is a block of code which only runs when it is called. A function can return data as a result.
					We can return multiple value in python function seperated them by comma
					Function name follows the same rules that we have for variables.
					
					Parameter: The variable defined in function during creation of function.
					Arguments: The values pass to the function during the calling of the function.
					
Note : Function definitions cannot be empty. If you need to create a function placeholder without any code, use the pass statement.


What is *args? : The *args parameter allows a function to accept any number of positional arguments.
Inside the function, args becomes a tuple containing all the passed arguments:
	
Example:
def my_function(*args):					// declaring only one argument with *
  print("Type:", type(args))
  print("First argument:", args[0])
  print("Second argument:", args[1])
  print("All arguments:", args)

my_function("Emil", "Tobias", "Linus")		//calling the finction with multiple argument
