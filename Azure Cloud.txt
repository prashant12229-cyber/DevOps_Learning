In the old Era, if any one have to setup a infrastructure for IT services than it need to have large number of resource to make it possible like

Cloud computing is a way to access all the service and resource over the internet instead of buy and manage it locally. we are actually renting the resource
Resource like :  Computer harware, Disk drives, DNS Services etc.

IAAS, PAAS, SAAS

Types: Public, Private, Hybrid

--------------------------Lecture 7 

Azure Storage account: Azure provide data storage account for data storage, it must be attached to a resource group.

Type:

BLOB: Object Storage for unstructured data (S3 Storage in AWS)
File: SMB file based share (Shared Storage like NFS)
Table: NoSQL Key Value storage (Like DynamoDB in AWS)
Disk : Persistant storage for VMs


Data Availability
LRS : Locally Redundant Storage : 3 copy of data set with in a single data center. if single data center goes down than data will not be avialble. ( availability = 11 9's behind 99.)
ZRS : Zero Redundant Storage : Data replicate to 3 different data center of 3 different availability zone. ( availability = 12 9's behind 99.)
GRS : Geo Redundant Storage : Data replicate to two regions (primary and secondary), and data will have 3 copy in one availability zone or data center, that protect the data from natural disaster. (availability = 16 9's behind 99.)
Geo Zone redundant storage : Primary will have 3 copy in 3 availability zone (each will have 1). (availability =16 9's behind 99.)
	
	
Security of data:
Access data via RBAC (Role based access control) : User will have to have permission or role that have permission to access that specific data.
Encryption : enable encryption on data
firewall : We can put a firewall in front of data that have some rule to access that data.
Private endpoint: accessing the data without internet, through privat endpoint.

Note: Storage account name should be unique, if someone in world has already have the name of storage account that you want to, than you will not be able to create with that name.


For storing the data into the storage account, we need to have container that we can create using "Storage browser"
and after creating a container we can drop our file there.


Permission to storage account : we have "IAM access control" option to manage the access, here select the role and assigned it to user in our cloud account.
